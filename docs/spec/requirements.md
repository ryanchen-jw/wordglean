# LinguaApp 需求規格 v0.1（草案）

> 2026-10-01 與創辦人六輪釐清後整理。調查依據：`docs/research/langapp-research.md`。標 ⚠️ 者為尚未實測、需原型驗證。

## 1. 產品定位

- 英文學習 Web App，使用者母語繁體中文；聽、說、讀、寫四面向。
- **只做手機版**（不做 RWD），以 PWA 形式可加入主畫面。
- **開源免費**：程式碼 AGPL-3.0 公開於 GitHub；另架一個官方站供一般人直接使用。單字資料（CC BY-SA 來源）放獨立資料夾、獨立授權。
- 第一版**不做遊戲化**（無連續天數、經驗值、排行榜、愛心）、**不做金流**。

## 2. 架構

| 層 | 選擇 | 理由 |
|---|---|---|
| 前端 | React＋Vite＋TailwindCSS（可用 shadcn） | 題型互動多 |
| 前端部署 | Cloudflare Pages | 免費 |
| 後端 | **不寫後端**；Supabase（PostgreSQL＋Auth＋Row Level Security） | 登入、同步、權限都由 Supabase 處理；他人可自架一份 |
| 語音合成（聽） | 手機瀏覽器跑 Kokoro-82M（約 90MB）；載入失敗或記憶體不足時退回系統內建聲音 | 地端開源模型 |
| 語音辨識（說） | 手機瀏覽器跑 Moonshine tiny（約 28MB，MIT）；Web Speech API 僅作最後後備 | 錄音不離開手機 |
| LLM（寫作批改、語法解釋） | OpenRouter，**使用者自帶帳號**（OAuth PKCE 一鍵授權或貼金鑰），金鑰只存使用者瀏覽器、由瀏覽器直接呼叫；使用者可自選模型 | 營運者零 LLM 成本、伺服器不碰金鑰 |
| 單字查義 | 內建 ECDICT（MIT，76 萬詞條，含音標、詞性），以 OpenCC s2twp 轉台灣繁體 | 免費、離線、無額度 |

Supabase 免費方案（二手來源核對）：500MB 資料庫、每月 5 萬活躍使用者、**閒置 7 天會自動暫停**——官方站需要定時喚醒機制（例如 Cloudflare 排程每日 ping）。

⚠️ iOS Safari 的 WASM 實務可用記憶體約 300MB，Kokoro 與 Moonshine 同時常駐有風險 → **開工第一步做語音原型**，在真實 iPhone／Android 上量載入時間、記憶體、延遲。

## 3. 帳號與資料

- **不登入也能完整使用**：進度與單字池存在手機（IndexedDB）。
- 登入方式：Google、Email 驗證碼（皆由 Supabase Auth 提供）。登入後把本機資料合併到雲端、跨裝置同步。
- 自架者若沒設定登入，App 仍可用（僅無同步）。

## 4. 分級與課綱

- 內部分級軸：CEFR A1–C1（多益官方對照無 C2）。
- 畫面顯示「B1｜約多益 xxx+」。對照依 ETS 官方 CEFR 門檻（聽力 / 閱讀：A1 60/60、A2 110/115、B1 275/275、B2 400/385、C1 490/455）；ETS 自述僅供參考。
- 單字資料：CEFR-J 1.6（7,801 字，標註出處可商用）＋ Octanove C1/C2（CC BY-SA）做分級；TSL（多益常用 1,250 字）與 NGSL 標為「多益常考」。**不可使用** Oxford 3000/5000、English Vocabulary Profile（版權）。
- 題庫由開發方用 LLM 批次產生（例句、閱讀短文、選項、參考答案、繁中翻譯），自動檢查（用字不超級距、答案唯一）後創辦人抽審，存成檔案進 repo。產題 LLM 費用由開發方一次性負擔。

## 5. 新手分級測驗

- 約 5 分鐘、純點選：列出各級單字，使用者勾「認識」。
- 混入少量假字（Yes/No 詞彙測驗法）抓灌水，勾假字扣分。
- 依各級認識比例推定起始級距；之後可在設定手動調整。

## 6. 題型（第一版）

| 面向 | 題型 | 需 LLM |
|---|---|---|
| 聽 | 聽音打字、聽音選答 | 否 |
| 說 | 跟讀：唸題目句 → 轉文字 → 與目標句逐字比對，標出錯字與漏字 | 否 |
| 讀 | 單字卡（綁定間隔重複）、選擇題、閱讀理解 | 否 |
| 寫 | 中翻英、造句：LLM 改錯並以繁中解釋語法 | 是 |

- **跟讀的轉文字可修改**：辨識完成後先讓使用者確認、必要時修正，再按送出；**分數以使用者送出的句子為準**（辨識不準時使用者本來就能修正後送出）。辨識結果與送出句的差異保留紀錄（日後可用來評估辨識準確度）。（2026-10-02 創辦人 G2 裁示，取代原「分數以辨識結果為準、修正只標記為模型聽錯」）
- **沒有 OpenRouter 金鑰時**：寫作題降級成「對照參考答案、自己判斷對錯」，並提示設定金鑰可獲 AI 批改。全 App 其餘功能不受影響。
- LLM 只用在語法糾錯與解釋；題目本身附的翻譯、答案都是預先產生好的。
- 跟讀錄音只用按鈕開始／結束，不做靜音偵測自動停錄（2026-10-01）。
- 無金鑰時的裝置端文法檢查（Harper）第一版不做，第二版再評估（2026-10-01）。

## 7. 單字池與間隔重複

- 演算法：**FSRS**（`ts-fsrs` 5.x，MIT，FSRS-6），在前端計算。預設目標記憶保留率 0.9；新字學習步驟 1 分鐘、10 分鐘；答錯重學 10 分鐘。
- 單字池每筆＝（使用者, 單字）：穩定度、難度、複習次數、遺忘次數、上次與下次複習時間、狀態、來源（課程／收藏）。
- 使用者可把任何單字（含點查時）加入「收藏單字庫」，進入同一個池排程複習。
- 每日新字數由使用者設定（預設 10）；待複習量過多時自動暫停出新字。
- 背景知識：坊間「5 分／30 分／12 小時／1／2／4／7／15 天」表查無一手出處；艾賓浩斯原始研究測的是重學節省率。FSRS 以每字、每人的記憶狀態動態排程，取代固定間隔表。

## 8. 課程結構與動線

- 課程三層：**級距 → 主題單元 → 小課**。主題可對應多益職場情境（辦公室、旅行⋯）。每小課約 5 分鐘、引入約 8 個新字，穿插聽說讀寫題；上完課的新字進入單字池。
- 每日動線：首頁一顆「今天的學習」→ **先複習到期單字，再接下一個小課**。另可自行進入單字庫與課程地圖。
- **介面全繁中**；英文只出現在學習內容裡。

## 9. 待定（開工後處理）

1. LLM 預設模型：用台灣學習者常見錯句實測候選模型後再定。
2. 「今天」的定義：以使用者裝置時區換日（暫定）。
3. 隱私說明：錄音一律不上傳；寫作內容只送使用者自選的 OpenRouter 模型。
