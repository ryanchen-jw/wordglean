# LinguaApp 設計 R1——主要畫面 ASCII 線框

> TASK-2 產出。依據：`docs/spec/requirements.md` v0.1。只對齊骨架與資訊層級，不代表視覺樣式與正式文案（文案佔位，TASK-4 定稿）。
> 基準：手機 390×844 直向。視覺方向見 `directions.md`；圈選頁 `pick.html` 內的線框區塊為本檔的唯讀副本，以本檔為準。

## 讀圖說明

- 中文字寬約為英文兩倍，線框只畫**左框線**與上下分隔線，右側不封口，避免框線歪掉。
- `[ 按鈕 ]` ＝可點按鈕；`( )`／`(•)` ＝單選；`[ ]`／`[x]` ＝勾選；`____` ＝輸入框；`▶` ＝播放；`●` ＝錄音；`≡`／`‹` ＝選單／返回。
- 每個畫面下方附三段：
  - **資訊層級**：①＝第一眼必須看到、②＝第二眼、③＝需要時才找。
  - **主要互動**：點了會怎樣。
  - **拇指熱區**：單手（右手握持）大拇指好按的區域是畫面下半部；主要動作一律放下方 1/3。
- 全 App 不出現連續天數、經驗值、排行榜、愛心（規格 §1）；介面文字全繁中，英文只出現在學習內容（規格 §8）。
- 底部導覽（暫定三格）：`今天`｜`課程`｜`單字庫`；設定由「今天」右上角進入。

## 1. 首頁「今天的學習」

```
+------------------------------------------
| 今天                               ⚙
| B1｜約多益 275+
+------------------------------------------
|
|   今天的學習
|   ─────────────────────
|   1  複習到期單字      24 個   約 6 分
|   2  下一課：辦公室 3－會議改期 約 5 分
|
|   [        開始今天的學習         ]   ← 主按鈕
|
+------------------------------------------
|  今天已完成
|  複習 0／24    新課 0／1
+------------------------------------------
|  其他
|  > 只複習單字
|  > 從課程地圖挑課
+------------------------------------------
|   今天   |    課程    |   單字庫
+------------------------------------------
```

狀態小圖：

```
(a) 今天都完成
|   今天的學習都完成了
|   明天約有 18 個單字到期
|   [   再上一課（選用）   ]

(b) 到期太多、暫停新字（規格 §7）
|   1  複習到期單字      132 個   約 30 分
|   2  新課暫停：先把複習量降下來
|      （待複習超過每日新字數 ×10 就暫停，預設 100 個；
|       降回 100 個以下自動恢復）

(c) 首次開啟、尚未分級
|   先花 5 分鐘找出你的起點
|   [      開始分級測驗      ]
|   > 跳過，從 A1 開始
```

- **資訊層級**：①「開始今天的學習」按鈕與兩步清單（先複習、再新課）；② 目前級距「B1｜約多益 275+」、今天完成度；③「只複習」「挑課」等次要入口、設定齒輪。
- **主要互動**：主按鈕依序帶進「單字卡複習（畫面 7）→ 小課（畫面 3–6）」，中途離開回首頁時清單會打勾；點級距文字可進設定調整級距。
- **拇指熱區**：主按鈕放在畫面中下段；設定齒輪在右上（低頻、可接受難按）。
- 完成度只呈現「今天做了多少」，不累計天數、不顯示連續紀錄。

## 2. 課程地圖

```
+------------------------------------------
| 課程
| [ A1 ][ A2 ][•B1 ][ B2 ][ C1 ]   ← 級距分頁
| B1｜約多益 275+
+------------------------------------------
|  辦公室            多益情境     3／8 課
|  ├ ✓ 1  自我介紹與部門
|  ├ ✓ 2  電話留言
|  ├ ▶ 3  會議改期                ← 目前這課
|  ├ ○ 4  請假與代理人
|  └ ○ 5…8
+------------------------------------------
|  旅行              多益情境     0／8 課
|  （收合）
+------------------------------------------
|  飲食與聚餐                     0／6 課
|  （收合）
+------------------------------------------
|   今天   |   •課程    |   單字庫
+------------------------------------------
```

小課詳情（點某一課，下方彈出）：

```
+------------------------------------------
|  辦公室 3｜會議改期        約 5 分
|  新字 8 個：reschedule, postpone, …
|  題型：聽 2・說 2・讀 3・寫 1
|  [          開始這一課          ]
+------------------------------------------
```

- **資訊層級**：① 目前這課（▶）與它所在的主題單元；② 級距分頁與各單元完成數；③ 已完成或未來課程的清單。
- **主要互動**：級距分頁切換（不鎖課，可跳級瀏覽）；點單元展開或收合；點課從底部彈出詳情，再按「開始這一課」。
- **拇指熱區**：級距分頁在上方（低頻）；詳情彈層的開始鈕在最底部。
- 結構為三層：級距 → 主題單元 → 小課（規格 §8）。

## 3. 小課進行中——聽（聽音打字／聽音選答）

```
+------------------------------------------
| ✕   ■■■■■□□□□□  5／12
+------------------------------------------
|  聽音打字
|  聽句子，把聽到的英文打出來
|
|         (  ▶  )        [ 慢速 ]
|        播放 2 次
|
|  _______________________________
|  _______________________________
|
+------------------------------------------
|  [  聽不出來  ]     [    檢查    ]
+------------------------------------------
|          （手機鍵盤）
```

```
聽音選答
|         (  ▶  )        [ 慢速 ]
|  他們決定怎麼處理會議？
|  ( ) A  Cancel it
|  ( ) B  Move it to Friday
|  ( ) C  Hold it online
|  [            檢查            ]
```

狀態小圖：

```
(a) 答對／答錯（題目卡下方滑出回饋條）
|  ✓ 正確
|  They moved the meeting to Friday.
|  [            繼續            ]

|  ✗ 差一點：moved → move
|  They moved the meeting to Friday.
|  他們把會議改到星期五。
|  [            繼續            ]

(b) 發音模型下載中（Kokoro 約 90MB，規格 §2）
|  發音模型下載中 42%  先用手機內建聲音
|  [ 只用 Wi-Fi 下載 ]

(c) 模型無法載入，改用系統聲音（不阻擋作答）
|  ⓘ 目前使用手機內建聲音
```

- **資訊層級**：① 播放鈕與作答區；② 題型名稱與一句說明；③ 進度條、慢速鈕。
- **主要互動**：播放（可重播、可切慢速）；聽音打字送出後逐字比對，標出錯字與漏字；聽音選答點選項再按檢查。
- **拇指熱區**：「檢查」「繼續」固定在底部；打字題的鍵盤彈出時，按鈕貼在鍵盤正上方。
- 題目上方只有進度，不顯示分數或經驗值。

## 4. 小課進行中——說（跟讀）

```
+------------------------------------------
| ✕   ■■■■■■□□□□  6／12
+------------------------------------------
|  跟讀
|  聽一次，再唸出這句
|
|  Could we push the meeting
|  to next Monday?
|  ▶ 聽示範
|
+------------------------------------------
|
|               (   ●   )
|           點一下開始錄音
|
|  > 現在不方便說話（這題先跳過）
+------------------------------------------
```

狀態小圖：

```
(a) 錄音中
|              ( ■ 點一下結束 )
|         ▁▃▅▇▅▃▁  0:03

(b) 辨識中（錄音只在手機上處理）
|         轉文字中…（不會上傳）

(c) 辨識完成——兩欄並列（規格 §6）
|  目標句
|  Could we push the meeting to next Monday?
|
|  辨識結果（計分用）
|  Could we [push] the [meetings] to next ___?
|                       錯字        漏字
|
|  你的修正（選填）
|  Could we push the meeting to next Monday?_
|  ⓘ 有修正時，這題標記為「模型聽錯」，不扣分也不加分
|
|  得分 6／8 字
|  [  再唸一次  ]      [    繼續    ]

(d) 只剩瀏覽器語音辨識可用（最後後備；調查文件要求告知使用者）
|  ⓘ 這次的語音會傳給瀏覽器廠商的伺服器處理
|  [ 了解，繼續 ]   [ 這題跳過 ]

(e) 未允許麥克風
|  需要麥克風才能跟讀
|  [ 允許麥克風 ]   > 這題跳過
```

- **資訊層級**：① 目標句與錄音鈕；② 辨識完成後的錯字與漏字標記、兩欄對照；③ 修正欄（選填）與「模型聽錯」說明。
- **主要互動**：點一下開始錄音、再點一下結束（規格 §6：按鈕開始／結束，不做靜音偵測自動停錄）；辨識完可在「你的修正」欄改字。分數一律以辨識結果計，有修正只標記為「模型聽錯」。
- **拇指熱區**：錄音鈕放在下 1/3 正中，直徑至少 72px；修正欄位於中段，點下去鍵盤彈出時，畫面自動捲到該欄。
- 唸錯的字以底線或色塊標示，不能只靠紅色區分（無障礙）。

選擇題

+------------------------------------------
|  選出最適合的字
|

|
|  ( ) A  postpone
|  ( ) B  promote
|  ( ) C  propose
|  ( ) D  protect
+------------------------------------------
|  [            檢查            ]
+------------------------------------------
```

```
閱讀理解
+------------------------------------------
| ✕   ■■■■■■■□□□  7／12
+------------------------------------------
|  ┌ 短文（可上下捲）
|  │ Dear team, due to the
|  │ holiday, our weekly
|  │ meeting will be moved…
|  └ ▼ 展開全文
|
|  1／2  為什麼要改期？

|  ( ) B  因為客戶要求
|  ( ) C  因為會議室被借走
+------------------------------------------

## 6. 小課進行中——寫（中翻英／造句）

```
+------------------------------------------
| ✕   ■■■■■■■■■□  11／12
+------------------------------------------
|  中翻英
|  我們可以把會議延到下週一嗎？
|
|  提示字：postpone
|
|  _______________________________
|  _______________________________
|  _______________________________
+------------------------------------------
|  [   跳過   ]       [  送出批改  ]
+------------------------------------------
```

狀態小圖：

```
(a) 有金鑰——AI 批改中
|  AI 批改中…（使用你的 OpenRouter 帳號）

(b) 有金鑰——批改結果
|  你的句子
|  Can we postpone the meeting to next Monday?
|  建議
|  Could we postpone the meeting until next Monday?
|  說明（繁中）
|  • until 表示「延到某時為止」，比 to 自然
|  • Could 比 Can 更客氣，適合職場請求
|  [ 我懂了，繼續 ]

(c) 無金鑰——降級成對照參考答案（規格 §6）
|  參考答案
|  Could we postpone the meeting until next Monday?
|  跟你的句子比一比：意思一樣嗎？
|  [  我寫對了  ]   [  我寫錯了  ]
|  ⓘ 設定 OpenRouter 帳號後可以用 AI 批改  > 去設定

(d) 批改失敗（額度用完或網路錯誤）
|  AI 批改暫時無法使用：今日免費額度已用完
|  先看參考答案 ▼   > 換模型
```

- **資訊層級**：① 中文題目與輸入框；② 批改後的建議句與繁中語法說明；③ 金鑰或額度提示。
- **主要互動**：輸入後送出；有金鑰就呼叫 LLM 批改，沒有就直接顯示參考答案讓使用者自評。自評結果只記錄、不影響單字排程。
- **拇指熱區**：送出鈕在鍵盤正上方。
- 無金鑰的降級提示每次只出現一行，不跳彈窗擋路。

## 7. 單字卡複習（FSRS）

```
+------------------------------------------
| ✕   複習  8／24
+------------------------------------------
|
|  ┌──────────────────────────
|  │
|  │        postpone
|  │        ▶  /pəʊstˈpəʊn/
|  │
|  │  The meeting was postponed.
|  │
|  └──────────────────────────
|
+------------------------------------------
|  [          翻面看答案          ]
+------------------------------------------
```

翻面後：

```
|  │        postpone        B1  多益常考
|  │        ▶  /pəʊstˈpəʊn/  v.
|  │  延後、延期
|  │  The meeting was postponed.
|  │  會議延期了。
+------------------------------------------
|  [ 忘了 ] [ 困難 ] [ 記得 ] [ 簡單 ]
|   10 分    1 天     3 天    8 天     ← 下次複習
+------------------------------------------
```

- **資訊層級**：① 英文單字（翻面後是中文釋義）；② 例句與發音；③ 級距標籤、多益常考標籤、下次複習時間。
- **主要互動**：點卡片或按鈕翻面；四顆評分鈕對應 FSRS 的 Again／Hard／Good／Easy，每顆鈕下方顯示「下次複習：x 天後」（調查 §1.4）。
- **拇指熱區**：四顆評分鈕橫排在最底部，每顆寬約 80px、高至少 56px；「記得」最常按，位置偏右、落在拇指最順的地方。
- 結束畫面只顯示「完成 24 個」與「明天約 x 個到期」，不給分數。

|  ▶ /ˈmiːtɪŋ/   n.
|
|  1. 會議；集會
|  2. 會面；相遇
|
|  [  ☆ 加入收藏單字庫  ]

狀態小圖：

## 10. 新手分級測驗

```
+------------------------------------------
| ✕   分級測驗   第 2／5 組
+------------------------------------------
|  勾選你「認識意思」的字
|  不確定就不要勾；裡面混了幾個不存在的假字
|
|  [x] schedule    [ ] brisk
|  [x] invoice     [ ] plinter
|  [ ] commute     [x] deadline
|  [ ] vendor      [ ] tremble
|  [ ] fortnight   [ ] blathe
|  [x] budget      [ ] reluctant
|
+------------------------------------------
|  已勾 4 個          [   下一組   ]
+------------------------------------------
```

結果：

```
|  你的起點
|  B1｜約多益 275+
|  A1 ███████████ 認識 95%
|  A2 █████████   認識 84%
|  B1 ██████      認識 58%
|  B2 ███         認識 25%
|  ⓘ 勾到 1 個假字，結果已向下修正
|
|  [   從 B1 開始   ]
|  > 想自己選級距
```

- **資訊層級**：① 單字勾選格；② 說明「不確定就別勾、有假字」；③ 組數進度。
- **主要互動**：點字切換勾選（整格可點，至少 44×44）；共 5 組約 5 分鐘；結果頁可接受建議或手動改級距（設定裡也能改，規格 §5）。
- **拇指熱區**：勾選格兩欄排列，「下一組」在底部。
- 假字不在結果頁逐一點名，只說明「勾到幾個、已修正」，避免使用者覺得被糾錯。
