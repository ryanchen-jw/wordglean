# LinguaApp 設計 R1——三個視覺方向與被挑戰的預設假設

> TASK-2 產出。骨架見 `wireframes.md`。本檔是三個方向的完整規格；創辦人在 `pick.html`（圈選頁）勾選「採用／混搭／否決」。
> 色碼唯一來源：`contrast_check.py`；本檔與圈選頁的色碼都從腳本抄出，對比度表為腳本實際輸出（見文末）。

## 共通前提（三方向都一樣）

- 手機 390×844 直向；內容最大寬 480px。
- 介面文字全繁中；英文只出現在學習內容。
- 字體全部採 OFL 授權，已在 `google/fonts` repo 的 `ofl/` 目錄確認 OFL.txt（2026-10-01）：Noto Sans TC、Noto Serif TC、Huninn、Inter、Literata、Nunito。
  - 圈選頁用 Google Fonts 載入，只為了預覽。正式上線改為自 host。
  - 依創辦人取捨「三平台視覺一致優先於流量」，保留中文 webfont，不提議改回系統字。
- 語意色一律「顏色＋圖示＋文字」三者並用（✓ 正確／✗ 差一點／ⓘ 提示），不能只靠紅綠區分。
- 觸控目標至少 44×44px；主要動作放在畫面下方 1/3。
- 字級階（三方向共用骨架，數值依方向微調）：

| 用途 | 大小 | 行高 |
|---|---|---|
| 說明小字 | 13px | 1.5 |
| 次要文字 | 15px | 1.6 |
| 中文內文 | 17px | 1.7 |
| 英文學習內容 | 19px | 1.5 |
| 小標 | 20px | — |
| 畫面標題 | 24px | — |
| 單字卡大字 | 34px | — |

  中文內文刻意比常見的 16px 大一級：手機上的中文筆畫密，17px 才好讀。

## 方向 A「安靜書桌」

**情緒關鍵字**：沉靜、專注、像在讀一本好書、成熟、不吵

**配色（淺色）**

| 角色 | 色碼 | 用途 |
|---|---|---|
| 底色 | `#F6F1E7` | 米白紙張 |
| 卡片 | `#FFFCF5` | 題目卡、彈層 |
| 內文 | `#1E2329` | 墨黑 |
| 次要文字 | `#595E66` | 說明、時間 |
| 邊線 | `#8F8778` | 輸入框、選項框 |
| 主色 | `#22467A` | 靛藍：主按鈕、連結、進度 |
| 答對 | `#2C6B3F` 字／`#E4F0E4` 底 | |
| 答錯 | `#A23A2C` 字／`#F7E3DE` 底 | |
| 提示 | `#7D5700` 字／`#F6EBCF` 底 | |

**配色（深色）**

| 角色 | 色碼 |
|---|---|
| 底 | `#1B1A17` |
| 卡片 | `#25231F` |
| 內文 | `#ECE6DA` |
| 次要 | `#ABA394` |
| 邊線 | `#7A7366` |
| 主色 | `#9DB8E3`（按鈕字 `#14223A`） |
| 答對 | `#8FCB9B` |
| 答錯 | `#F0A296` |
| 提示 | `#E3C075` |

**中英字體**

| 用途 | 字體 |
|---|---|
| 標題、中文翻譯 | Noto Serif TC（思源宋體），可變字重 200–900 |
| 介面文字 | Noto Sans TC（思源黑體） |
| 英文學習內容（單字卡、例句、短文） | Literata（為螢幕閱讀設計的書本字體），有光學尺寸 |

宋體只用在 20px 以上的標題和中譯卡，小字一律用黑體，因為宋體細橫線在手機小字容易糊。

**圓角與密度**
- 圓角：按鈕與卡片 10px，彈層上緣 16px，選項 8px。
- 密度：中等；卡片內距 20px，清單列高 56px。
- 陰影幾乎不用，改以細邊線區隔，營造紙面的平。

**參考產品**（只參照氣質，不抄）：Readwise Reader、Kindle 閱讀畫面、Anki 的克制（但更好看）、Apple Books

**價值／成本**

| | 內容 |
|---|---|
| 換到什麼 | 最貼近「讀書」的專注感，成人、多益備考族群容易信任；英文用書本字體，閱讀理解題長文最舒服 |
| 相對成本 | **中（約 1.2×）**：兩套中文字體（宋＋黑），字體流量最高；宋體在 Android 舊機上要驗收糊不糊 |
| 多花在哪 | 多一套中文字體的載入與驗收；紙感底色在深色模式要另外調暖色，色票多一輪 |
| 風險 | 可能顯得「太嚴肅」，對 A1–A2 初學者略有距離感 |

- 圓角：按鈕 8px，卡片 12px，彈層上緣 16px，選項 8px。

**價值／成本**

| 風險 | 個性最弱，容易像「又一個工具 App」；學習動機要靠內容撐，介面不給情緒 |

## 方向 C「溫暖陪伴」

**情緒關鍵字**：親切、放鬆、被鼓勵、柔軟、不幼稚

**配色（淺色）**

| 角色 | 色碼 | 用途 |
|---|---|---|
| 底色 | `#FFF6EC` | 奶茶白 |
| 卡片 | `#FFFFFF` | |
| 內文 | `#2B2119` | 深咖啡 |
| 次要文字 | `#6A584A` | |
| 邊線 | `#A08A78` | |
| 主色 | `#B2431D` | 磚橘：主按鈕、連結、進度 |
| 答對 | `#2B7149` 字／`#E2F2E6` 底 | |
| 答錯 | `#B0261A` 字／`#FCE4DF` 底 | |
| 提示 | `#835600` 字／`#FBEBC8` 底 | |

**配色（深色）**

| 角色 | 色碼 |
|---|---|
| 底 | `#1E1814` |
| 卡片 | `#2A221C` |
| 內文 | `#F3E9DF` |
| 次要 | `#B9A898` |
| 邊線 | `#85735F` |
| 主色 | `#FFA27F`（按鈕字 `#3A1405`） |
| 答對 | `#8DD3A6` |
| 答錯 | `#FFA294` |
| 提示 | `#EDC273` |

**中英字體**

| 用途 | 字體 |
|---|---|
| 標題與大字 | Huninn（粉圓，justfont 出品，台灣字形標準的圓體）。只有 400 一個字重 |
| 介面與中文內文 | Noto Sans TC |
| 英文學習內容 | Nunito（圓頭無襯線，可變字重） |

粉圓只有一個字重，所以只用在標題；粗細層次靠 Noto Sans TC 撐。另一個候選 Chiron GoRound TC 有可變字重，但字形基於香港標準，與台灣用字習慣不完全一致，所以不選。

**圓角與密度**
- 圓角：按鈕全圓（膠囊形），卡片 20px，彈層上緣 28px，選項 16px。
- 密度：寬鬆；卡片內距 24px，清單列高 60px。
- 主色可在大區塊用淡色底（例：首頁「今天的學習」卡片）。

**參考產品**：Headspace、Finch、Duolingo（只取圓潤與色彩溫度，不取任何遊戲化元素）

**價值／成本**

| | 內容 |
|---|---|
| 換到什麼 | 對初學者最友善，降低「學英文好難」的壓力；在沒有遊戲化的前提下，靠介面本身提供情緒支持 |
| 相對成本 | **中高（約 1.4×）**：三套字體（粉圓＋黑體＋Nunito）；大圓角與寬鬆密度會讓單字庫一頁裝的字變少 |
| 多花在哪 | 這個方向通常會被要求加插畫，見假設 #5；不加插畫時，空狀態要靠排版撐住 |
| 風險 | 稍不注意會顯得幼稚，與「成人、多益」族群拉開距離；磚橘主色與答錯紅色相近，要靠圖示與文字區分（已列共通前提） |

| | A 安靜書桌 | B 清爽工具 | C 溫暖陪伴 |
|---|---|---|---|

| 主色 | 靛藍 | 深青綠 | 磚橘 |

| 英文字體 | Literata | Inter | Nunito |
| 圓角 | 10px | 8–12px | 膠囊／20px |
| 密度 | 中 | 緊 | 鬆 |

## 被挑戰的預設假設

| # | 預設假設 | 建議 | 換到什麼 | 成本 |
|---|---|---|---|---|
| 1 | 只做淺色模式 | **第一版就做深色，預設跟隨系統，設定可手動切換**。三方向都已附深色色票並實算對比 | 睡前、通勤暗處學習很常見；手機 OLED 螢幕省電；不做會被當成缺功能 | 中：tokens 雙套，每個畫面驗收兩次（設計＋QA 約 +20%）。TASK-3 一開始就把顏色寫成變數，日後補做會更貴 |
| 2 | 只做直向 | **設計只做直向，但橫過來不能壞版**：內容置中、最大寬 480px，不另外設計橫向 | 手機橫放看影片後切回來不會破版 | 極低：一條版面規則＋一張截圖驗收 |
| 3 | 主要按鈕放哪都行 | **單手熱區規則**：主要動作（檢查、繼續、評分、錄音）固定在下方 1/3，全寬或置中，左右手都好按；頂部只放低頻功能（設定、關閉） | 通勤單手拿手機也能連續作答，不用換手 | 低：線框已照此規則畫；元件規格要寫死 |
| 4 | 字級用預設就好 | **App 內提供三段字級（標準／大／特大）**，全站用相對單位，特大不破版。原因：iPhone 網頁不會自動跟系統「更大字體」設定 | 年長學習者、視力較弱者也能用；符合無障礙 | 中低：每個畫面要在「特大」各驗一次（QA 約 +10%） |
| 5 | 需要吉祥物／插畫系統 | **第一版不做吉祥物**；空狀態與分級結果用文字＋簡單線條圖示。選方向 C 且想加插畫，再另開任務評估 | 避免與「不做遊戲化、成人感」衝突；省下角色設計 | 不做＝0。做吉祥物＝角色設計＋多表情＋各狀態插圖，屬外包等級成本（數萬元起，未估價） |
| 6 | 答對答錯用紅綠就好 | **顏色＋圖示＋文字三者並用**，錯字用底線與色塊雙重標示 | 約 8% 男性有紅綠色弱，只靠顏色會看不出對錯 | 極低：只是元件規格 |
| 7 | 動效越多越好／越少越好 | **只在答對回饋與翻卡用短動效（≤200ms），不做彩帶或慶祝動畫**；系統開「減少動態效果」時全部關掉 | 有回饋感，但不吵、不像遊戲 | 低 |
