## typeset 發現與處理

- 字級階：13／15／17／19／20／24／34。英文內容的 19 和卡片標題的 20 很接近，但兩者字體不同（英文 vs 中文粗體），角色區分得出來，不改。
- 原本有兩處寫死 12px：標籤（B1、多益常考）和評分鈕的「3 天」。已改用 caption token（13px），全站不再有小於 13px 的字。
- 字重只用 400／500／600（英文）／700（標題、主按鈕），沒有額外字重。
- 字體家族：主案為思源黑體＋Plus Jakarta Sans，音標另用 Noto Sans（只作用在音標字元）。

## polish 發現與處理

- **色碼**：`review.src.html` 中沒有寫死的色碼，全部經 `--lg-*` token（grep 驗證 0 筆）。
- **數字對齊**：計數、題號、評分時間都用等寬數字（tabular-nums）。
- **焦點**：焦點框統一 3px `focus`，深淺兩模式對比都 ≥3（tokens 測試涵蓋）。
- **動效**：只用 transform 與 opacity；減少動態效果時時長為 0（tokens.css）；轉圈動畫也在該設定下停止。
- **未畫的狀態**（列入 G2 後微調或 TASK-11）：離開小課的確認框、清除資料的二次確認框、小課完成頁。
