# LinguaApp 設計 R1b——依 ui-ux-pro-max 重做的三個視覺方向

> TASK-2 第二輪方向探索。G1 第一輪結果：A／B／C 三方向全部未採用；創辦人要求改用 ui-ux-pro-max skill 重新設計三版。
> 骨架沿用 `docs/design/r1/wireframes.md`。本檔是三方向的完整規格，創辦人在 `pick.html` 圈選。
> 色碼唯一來源：`docs/design/r1/contrast_check.py` 的 `PALETTES_R1B`；對比度表由 `python docs/design/r1/contrast_check.py r1b` 實際輸出（文末）。

## 已定案的約束（G1 創辦人全數同意，本輪不再收意見）

1. **深色模式**：第一版就做，預設跟隨系統，設定可手動切換。三方向都附深色色票並實算。
2. **方向**：只設計直向；橫過來時內容置中、最大寬 480px，不能壞版。
3. **單手熱區**：主要動作（檢查、繼續、評分、錄音）固定在下方 1/3。
4. **字級**：App 內提供三段字級（標準／大／特大），特大不能破版。
5. **插畫**：不做吉祥物；空狀態用文字＋簡單線條圖示。
6. **對錯回饋**：顏色＋圖示＋文字三者並用。
7. **動效**：只在答對回饋與翻卡用短動效（≤200ms）；系統開「減少動態效果」時全部關掉。

其他沿用 R1 的共通前提：介面全繁中、觸控目標 ≥44px、中文內文 17px。字體全部 OFL，已在 `google/fonts` 的 `ofl/` 確認有 OFL.txt。

## skill 怎麼用的（共通說明）

- 查詢指令：`python ~/.claude/skills/ui-ux-pro-max/scripts/search.py "<查詢>" --design-system [旋鈕]`，三方向各來自不同的查詢或旋鈕組合。
- 補充查詢：
  - `"minimal flat mobile app" --domain style`
  - `"soft rounded friendly adult" --domain style`
  - `"editorial reading serif"`、`"clean modern sans readable"`、`"friendly rounded adult approachable" --domain typography`
  - `"education learning" --domain color`
- **對三方向都一樣的否決**：
  - skill 對每個查詢都附了「Pattern」：Hero＋Testimonials、Product Demo、Feature Showcase。這些是**行銷登陸頁結構**，不適用 App 畫面，一律不採用；畫面結構以 R1 線框為準。
  - skill 對每個查詢都附了 GSAP「捲動揭示」動效。App 沒有行銷式捲動頁，而且違反定案約束 7，一律不採用。
- **skill 資料庫沒有中文字體**：中文字體由我自選 OFL 字體，並逐一在 Google Fonts 驗證。
- **R1 遺留問題修正**：R1 發現英文字體顯示音標字元（ʊ、ə）會退回別的字體。R1b 三方向的音標一律用 Noto Sans（字元集涵蓋 IPA）。

## 方向 1「Swiss 專注」

**查詢**：`"flashcard study tool focused calm" --design-system --variance 2 --density 7 --motion 2`

**skill 回傳**
- 風格：Minimalism & Swiss Style（深淺色皆支援，無障礙風險低）
- 色票：學習紫 `#7C3AED`＋答對綠 `#059669`
- 字體：Varela Round＋Nunito Sans
- 旋鈕結果：置中極簡、標準密度、細微動效

**採用**
- Swiss 風格：網格、留白、高對比、不用漸層與陰影
- 主色紫 `#7C3AED`（白字對比 5.70，原值即過 AA）
- 次要文字 `#475569`、內文 `#0F172A`，沿用 skill 原值
- 密度 7：間距 16–64px
- 細微動效等級

**否決與理由**

| skill 推薦 | 否決理由 | 改用 |
|---|---|---|
| Varela Round＋Nunito Sans | skill 自己標註「適合兒童產品」；圓頭字與 Swiss 的幾何理性衝突 | 英文 DM Sans（skill 字體配對庫「Premium Sans」） |
| 答對綠 `#059669` | 白底對比只有 3.77，不夠當文字色 | 加深為 `#047857` |
| 邊線 `#EFE7FC` | 對白底幾乎看不見，輸入框邊界需 ≥3:1 | `#7C8091` |

**情緒關鍵字**：清楚、理性、專注、乾淨、有秩序

**配色**

| 角色 | 淺色 | 深色 |
|---|---|---|
| 底色 | `#FAF8FD` | `#0D0B12` |
| 卡片 | `#FFFFFF` | `#17141F` |
| 內文 | `#0F172A` | `#EDEBF3` |
| 次要文字 | `#475569` | `#A7A3B6` |
| 邊線 | `#7C8091` | `#6C6681` |
| 主色 | `#7C3AED`（按鈕字 `#FFFFFF`） | `#B9A2FF`（按鈕字 `#1A0B3B`） |
| 輔色（標籤、連結） | `#5B21B6` | `#D4C6FF` |
| 答對（字／底） | `#047857`／`#E6F4EE` | `#5ED3A2`／`#10291E` |
| 答錯（字／底） | `#B91C1C`／`#FCEAEA` | `#FF9E9E`／`#33171A` |
| 提示（字／底） | `#8A4B0B`／`#FBF0DF` | `#F2C26E`／`#2D2312` |

**中英字體**

| 用途 | 字體 |
|---|---|
| 中文（標題與內文） | Noto Sans TC（思源黑體）；標題 700、內文 400 |
| 英文學習內容 | DM Sans（幾何無襯線，有光學尺寸軸） |
| 音標 | Noto Sans |

**圓角與密度**
- 圓角：按鈕與卡片 4px，選項 4px，彈層上緣 12px。直角感是這個方向的辨識點。
- 密度：卡片內距 16px，清單列高 52px。
- 不用陰影，以 1px 細線和留白分層；選取中的選項改用 2px 主色外框。

**參考產品**：Apple「提醒事項」、Bear、Craft、瑞士國際主義海報的網格傳統

**價值／成本**

| | 內容 |
|---|---|
| 換到什麼 | 資訊最清楚，單字庫與設定這類清單畫面效率最高；直角、無陰影，深色模式最好做 |
| 相對成本 | **低（1.0 倍，基準）**：一套中文字體加一套英文字體；元件幾乎不需要陰影與動效 |
| 多花在哪 | 不多花。但 Swiss 靠字級與留白撐場，排版要嚴格守網格 |
| 風險 | 偏冷靜理性，A1–A2 初學者可能覺得少了溫度 |

## 方向 2「柔光層次」

**查詢**：`"meditation wellness app soft calm" --design-system --variance 5 --density 3 --motion 3`

**skill 回傳**
- 風格：Neumorphism（無障礙風險 **high**，深色 conditional）
- 色票：平靜薰衣草紫＋正念綠，數值與方向 1 的查詢相同：`#7C3AED`／`#059669`
- 字體：Lora＋Raleway
- 旋鈕結果：平衡、寬鬆密度、細微動效

**採用**
- 正念綠作主色。因為紫已給方向 1，為了三方向可區分，這裡取綠，加深為 `#047857` 以符合白字 AA。
- 薰衣草紫降為輔色，用在標籤、選取態，以及底色 `#F5F3FA` 的微紫調。
- Lora 作英文學習內容字體：閱讀理解長文最受益。
- 寬鬆密度 3：間距 24–96px。

**否決與理由**

| skill 推薦 | 否決理由 | 改用 |
|---|---|---|
| Neumorphism | skill 自標無障礙風險 high：浮雕陰影讓按鈕邊界對比不足，深色模式只是 conditional，違反定案約束 1 | 同庫的 **Soft UI Evolution**（`"soft rounded friendly adult" --domain style` 結果，風險 low、深淺皆支援）：保留柔和陰影層次，但邊界用可量測的對比 |
| Raleway | UI 全中文，用不到英文介面字體；Raleway 預設舊式數字，「24 個」這類數字高低不齊 | 中文介面用 Noto Sans TC |
| 霞鶩文楷 TC（我初選，非 skill 推薦） | 它的 README 自述採「傳承字形」，並建議要臺灣教育部標準字形者改用芫荽 | **芫荽 Iansui**（臺標字形，OFL） |

**情緒關鍵字**：平靜、柔和、被照顧、有呼吸感、成熟

**配色**

| 角色 | 淺色 | 深色 |
|---|---|---|
| 底色 | `#F5F3FA` | `#121118` |
| 卡片 | `#FFFFFF` | `#1C1A24` |
| 內文 | `#1C1A27` | `#ECEAF4` |
| 次要文字 | `#57536A` | `#A9A5BA` |
| 邊線 | `#8C88A0` | `#6D687E` |
| 主色 | `#047857`（按鈕字 `#FFFFFF`） | `#6EDBAE`（按鈕字 `#05271B`） |
| 輔色（薰衣草） | `#6E56CF` | `#B9A8F5` |
| 答對（字／底） | `#0B6B4A`／`#E3F3EA` | `#7FE0B4`／`#11291F` |
| 答錯（字／底） | `#B42318`／`#FBE7E4` | `#FFA39A`／`#34191A` |
| 提示（字／底） | `#7A4E00`／`#F6ECD5` | `#EFC777`／`#2C2414` |

**中英字體**

| 用途 | 字體 |
|---|---|
| 標題、中文翻譯 | 芫荽 Iansui（臺標楷書手寫感，只有 400 一個字重） |
| 介面與中文內文 | Noto Sans TC |
| 英文學習內容 | Lora（可變字重 400–700） |
| 音標 | Noto Sans |

**圓角與密度**
- 圓角：按鈕 14px，卡片 16px，選項 12px，彈層上緣 24px。
- 密度：寬鬆；卡片內距 24px，清單列高 60px。
- 陰影：兩層柔和陰影（`0 1px 2px` 加 `0 8px 24px`，低透明度）。深色模式改用較亮的卡片色分層，不靠陰影。

**參考產品**：Calm、Oura、Apple「正念」

**價值／成本**

| | 內容 |
|---|---|
| 換到什麼 | 降低學習壓力，像在安靜空間裡練習；楷體標題帶人文溫度但不幼稚；長文閱讀最舒服 |
| 相對成本 | **中（約 1.3 倍）**：三套字體（芫荽＋黑體＋Lora）；兩層陰影在深淺色都要調；寬鬆密度讓單字庫一頁裝的字變少 |
| 多花在哪 | 陰影與分層的細調；芫荽只有一個字重，標題層次要靠字級撐 |
| 風險 | 主色綠和「答對」綠同色系，答對與主按鈕可能混淆，須靠 ✓ 圖示與文字區分（定案約束 6 已涵蓋） |

## 方向 3「暖橘模組」

**查詢**：`"education app warm encouraging accessible" --design-system --variance 6 --density 3 --motion 3`

另參照 `"language learning app adult minimal" --design-system`（無旋鈕）：它的產品色票列「Language Learning App」同樣給靛藍＋進度綠，風格同為 Claymorphism。

**skill 回傳**
- 風格：Claymorphism（深色 conditional，並註明「avoid for this product」）
- 色票：活潑靛藍 `#4F46E5`＋活力橘 `#EA580C`
- 字體：Baloo 2＋Comic Neue
- 反模式欄寫著「Dark modes」
- 旋鈕結果：平衡、寬鬆密度、細微動效

**採用**
- 橘作主色、靛藍作內文與輔色，讓三方向主色分屬紫／綠／橘三個色相。
  - 橘加深為 `#C2410C`，白字對比 5.18。
  - 靛藍 `#1E1B4B` 作內文，`#4F46E5` 作標籤與連結。
- 微靛藍底色 `#EEF1FF`（skill 原底色 `#EEF2FF` 的微調）。
- Claymorphism 中不幼稚的部分：大圓角（20px）、按下時輕微縮放（0.97）、單層柔和陰影。
- 寬鬆密度。

**否決與理由**

| skill 推薦 | 否決理由 | 改用 |
|---|---|---|
| Claymorphism 本體（3–4px 粗邊框、內外雙陰影、回彈動畫） | skill 自述關鍵字是「toy-like、playful、children's apps」，違反「成人、不幼稚、無遊戲化」；回彈動畫也超出約束 7 | 版面改採同庫 **Bento Box Grid**（`"soft rounded friendly adult" --domain style` 結果，風險 low）：首頁以大小不一的模組卡呈現今天的任務 |
| Baloo 2＋Comic Neue | skill 字體庫標註「kids、children's apps」 | 英文 Plus Jakarta Sans（skill 字體庫「Friendly SaaS」：友善但專業） |
| 反模式「Dark modes」 | 與定案約束 1 衝突 | 照做深色模式 |
| 答對綠 `#15803D` | 腳本實算：對答對底只有 4.44，未達 AA | 加深為 `#116B34`（5.85） |

**情緒關鍵字**：有精神、俐落、鼓勵但不吵、現代、清楚分區

**配色**
